# 🧪 Praktikum 2 — Menampilkan Informasi Pengguna Linux

## 📌 Deskripsi

Pada praktikum ini, dilakukan pembuatan Shell Script menggunakan text editor Nano untuk menampilkan informasi pengguna yang sedang login pada sistem operasi Linux.

Program menggunakan perintah `echo` untuk menampilkan pesan dan perintah `who` untuk mengetahui pengguna yang sedang aktif atau login.

## 🎯 Tujuan Praktikum

- Memahami cara membuat Shell Script menggunakan Nano.
- Mengenal penggunaan perintah `echo`.
- Memahami fungsi perintah `who`.
- Mengetahui informasi pengguna yang sedang login di Linux.
- Menjalankan program Bash melalui terminal.

## 💻 1. Membuat File Shell Script

Buat file baru bernama `p2.sh` menggunakan perintah:

```bash
nano p2.sh
```

Masukkan kode berikut ke dalam editor Nano:

```bash
#!/bin/bash

echo "Program p2"

who
```

Simpan file dengan menekan `Ctrl + O`, kemudian `Enter`. Keluar dari Nano menggunakan `Ctrl + X`.

## 🔍 2. Penjelasan Kode Program

### 1. Menentukan Interpreter

```bash
#!/bin/bash
```

Menentukan bahwa program dijalankan menggunakan interpreter Bash.

### 2. Menampilkan Pesan

```bash
echo "Program p2"
```

Perintah `echo` digunakan untuk menampilkan tulisan `Program p2` pada terminal.

### 3. Menampilkan Informasi Pengguna

```bash
who
```

Perintah `who` digunakan untuk menampilkan informasi mengenai pengguna yang sedang login pada sistem Linux.

Informasi yang dapat ditampilkan meliputi:

- Nama pengguna.
- Terminal yang digunakan.
- Waktu pengguna mulai login.
- Informasi tambahan seperti alamat atau host asal login jika tersedia.

## 🚀 3. Menjalankan Program

Setelah file selesai dibuat, jalankan menggunakan perintah:

```bash
bash p2.sh
```

Atau berikan izin eksekusi terlebih dahulu:

```bash
chmod +x p2.sh
```

Kemudian jalankan:

```bash
./p2.sh
```

## 📋 4. Hasil Praktikum

Ketika program dijalankan, terminal akan menampilkan:

1. Tulisan `Program p2`.
2. Informasi pengguna yang sedang login pada sistem Linux.

Hasil perintah `who` dapat berbeda tergantung jumlah pengguna dan sesi login yang sedang aktif.

Jika hanya terdapat satu sesi login, informasi yang ditampilkan biasanya hanya satu baris.

## 📖 5. Kesimpulan

Pada praktikum kedua, telah dipelajari cara membuat dan menjalankan Shell Script untuk menampilkan informasi pengguna Linux.

Perintah `echo` digunakan untuk menampilkan pesan, sedangkan perintah `who` digunakan untuk mengetahui informasi pengguna yang sedang login.

Praktikum ini memberikan pemahaman dasar mengenai penggunaan perintah Linux melalui program Shell Script.
