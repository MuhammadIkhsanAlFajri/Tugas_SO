# 🔧 Praktikum 3 — Menjalankan Perintah Process pada Linux

## 📌 Deskripsi

Pada praktikum ini, dilakukan pembuatan program Shell Script menggunakan text editor Nano pada sistem operasi Linux.

Program dibuat menggunakan bahasa Bash untuk menampilkan pesan teks dan menjalankan perintah `ps` guna melihat proses yang sedang berjalan pada sistem.

## 🎯 Tujuan Praktikum

- Mengenal penggunaan text editor Nano pada Linux.
- Memahami cara membuat file Shell Script.
- Memahami struktur dasar program Bash.
- Mengenal perintah `ps` untuk melihat proses yang berjalan.
- Menjalankan program Shell Script melalui terminal.

## 💻 1. Membuat File Shell Script

Langkah pertama adalah membuat file baru bernama `p3.sh` menggunakan Nano.

Jalankan perintah berikut pada terminal:

```bash
nano p3.sh
```

Kemudian masukkan kode berikut:

```bash
#!/bin/bash

echo "Program p3"

ps
```

Simpan file dengan menekan `Ctrl + O`, kemudian `Enter`, lalu keluar menggunakan `Ctrl + X`.

## 🔍 2. Penjelasan Kode

### 1. Menentukan Interpreter

```bash
#!/bin/bash
```

Digunakan untuk menentukan bahwa program dijalankan menggunakan interpreter Bash.

### 2. Menampilkan Pesan

```bash
echo "Program p3"
```

Digunakan untuk menampilkan tulisan `Program p3` pada terminal ketika program dijalankan.

### 3. Menampilkan Proses

```bash
ps
```

Perintah `ps` (Process Status) digunakan untuk menampilkan informasi proses yang sedang berjalan.

Informasi yang ditampilkan antara lain:

- PID (Process ID), yaitu nomor identitas setiap proses.
- TTY, yaitu terminal yang digunakan oleh proses.
- TIME, yaitu waktu CPU yang digunakan proses.
- CMD, yaitu perintah atau program yang sedang dijalankan.

## ▶️ 3. Menjalankan Program

Setelah file selesai dibuat, berikan izin eksekusi menggunakan perintah:

```bash
chmod +x p3.sh
```

Kemudian jalankan program:

```bash
./p3.sh
```

## 📋 4. Hasil Praktikum

Ketika program dijalankan, terminal akan menampilkan:

1. Pesan `Program p3`.
2. Daftar proses yang sedang berjalan.
3. Informasi PID dari setiap proses.
4. Informasi terminal, waktu CPU, dan perintah yang sedang berjalan.

Melalui perintah `ps`, pengguna dapat mengetahui proses-proses yang sedang aktif pada terminal Linux.

## 📖 5. Kesimpulan

Pada praktikum ketiga, telah dipelajari cara membuat dan menjalankan Shell Script menggunakan Nano.

Perintah `echo` digunakan untuk menampilkan pesan pada terminal, sedangkan perintah `ps` digunakan untuk melihat daftar proses yang sedang berjalan beserta informasi PID-nya.

Praktikum ini memberikan pemahaman dasar mengenai pengelolaan proses (process management) pada sistem operasi Linux.
