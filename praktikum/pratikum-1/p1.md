# 🧪 Praktikum 1 — Membuat Shell Script pada Linux

## 📌 Deskripsi

Pada praktikum ini, dilakukan pembuatan program Shell Script menggunakan text editor Nano pada sistem operasi Linux.

Program dibuat menggunakan bahasa Bash untuk menampilkan pesan teks dan melihat daftar file beserta informasi detailnya melalui terminal.

## 🎯 Tujuan Praktikum

- Mengenal penggunaan text editor Nano pada Linux.
- Memahami cara membuat file Shell Script.
- Mengenal struktur dasar program Bash.
- Memahami penggunaan perintah `echo` dan `ls -l`.
- Menjalankan program Shell Script melalui terminal.

## 💻 1. Membuat File Shell Script

Langkah pertama adalah membuat file baru bernama `p1.sh` menggunakan Nano.

Jalankan perintah berikut pada terminal:

```bash
nano p1.sh
```

Setelah editor Nano terbuka, masukkan kode berikut:

```bash
#!/bin/bash
echo "Program p1"
ls -l
```

Simpan file dengan menekan `Ctrl + O`, kemudian `Enter`. Untuk keluar dari Nano, tekan `Ctrl + X`.

## 🔍 2. Penjelasan Kode Program

### 1. Menentukan Interpreter

```bash
#!/bin/bash
```

Digunakan untuk menentukan bahwa program dijalankan menggunakan interpreter Bash.

### 2. Menampilkan Pesan

```bash
echo "Program p1"
```

Perintah `echo` digunakan untuk menampilkan teks `Program p1` pada terminal.

### 3. Menampilkan Daftar File

```bash
ls -l
```

Perintah `ls -l` digunakan untuk menampilkan daftar file dan direktori dalam format panjang (long listing).

Informasi yang ditampilkan meliputi:
- Hak akses file.
- Jumlah hard link.
- Pemilik file.
- Grup pemilik.
- Ukuran file.
- Tanggal dan waktu modifikasi.
- Nama file atau direktori.

## 🚀 3. Menjalankan Program

Setelah file selesai dibuat, jalankan program dengan perintah:

```bash
bash p1.sh
```

Alternatifnya, berikan izin eksekusi terlebih dahulu:

```bash
chmod +x p1.sh
```

Kemudian jalankan:

```bash
./p1.sh
```

## 📋 4. Hasil Praktikum

Ketika program dijalankan, terminal akan menampilkan:

1. Pesan `Program p1`.
2. Daftar file dan direktori pada lokasi kerja saat ini.
3. Informasi detail dari setiap file dan direktori yang ditampilkan.

Perintah `ls -l` menampilkan isi direktori kerja saat script dijalankan, bukan secara khusus riwayat perintah terminal.

## 📖 5. Kesimpulan

Pada praktikum pertama, telah dipelajari cara membuat dan menjalankan Shell Script menggunakan Nano.

Penggunaan `echo` memungkinkan program menampilkan pesan pada terminal, sedangkan `ls -l` digunakan untuk melihat daftar file dan informasi detailnya.

Praktikum ini menjadi dasar untuk memahami pembuatan program sederhana menggunakan Bash di Linux.
