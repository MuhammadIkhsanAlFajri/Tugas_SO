Repository ini berisi kumpulan materi, dokumentasi, dan hasil praktikum mata kuliah **Sistem Operasi**.

Dokumentasi ini dibuat sebagai catatan pembelajaran mengenai sistem operasi Linux, penggunaan terminal, perintah dasar Linux, serta pengelolaan proses dan Shell Scripting.

---

## 🎯 Tujuan Pembelajaran

- Memahami konsep dasar sistem operasi Linux.
- Mengenal dan menggunakan perintah-perintah Linux.
- Memahami konfigurasi environment dan profile.
- Mempelajari pengelolaan proses pada Linux.
- Mempraktikkan penggunaan Shell Scripting.
